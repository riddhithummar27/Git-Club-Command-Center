// 01. ABOUT SESSION

Designed specifically for sophomore and pre-final year engineering students at CHARUSAT. We will cover the mechanics of the object database (blobs, trees, commits, tags), mastering pull requests, interactive rebasing, and collaborating seamlessly on production-scale open source repositories.

// 02. TIMELINE SCHEDULE

16:00 - 16:30 • Intro to Version Control
The architecture of Git, commit graph traversal, and setup of cryptographic signing.
16:30 - 17:15 • Branching & PR Workflow
Feature branches, upstream syncing, 3-way merge resolutions, and commit hygiene.
17:15 - 17:50 • Team Workflow & CI/CD Hooks
Automating checks using GitHub Actions and CHARUSAT repository deploy templates.
17:50 - 18:15 • Q&A and Hands-on Clinic
Debugging attendee repository states and issuing digital verified credentials.
