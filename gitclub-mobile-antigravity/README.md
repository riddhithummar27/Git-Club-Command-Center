# Git Club mobile UI pages

Standalone mobile-friendly HTML copies for the Git Club pages. Open `gitclub-mobile.html` to start at the Command Center. Navigation links connect the bundled pages.

## Included pages

- `gitclub-mobile.html` — Command Center
- `gitclub-mobile-events.html` — Events
- `gitclub-mobile-members.html` — Members
- `gitclub-mobile-projects.html` — Projects
- `gitclub-mobile-announcements.html` — Announcements
- `gitclub-mobile-analytics.html` — Analytics
- `gitclub-mobile-notifications.html` — Notifications
- `gitclub-mobile-settings.html` — Settings
- `gitclub-mobile-messages.html` — Messages

The local Git Club logo is in `frontend/public/gitclub_logo.png`. Tailwind CSS, fonts, icons, and some avatars load from external CDNs and need internet access.
